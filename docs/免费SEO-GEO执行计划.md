# HR工作站：免费SEO与GEO执行计划

2026-10-24用户确认。目标是让HR找到、看懂并实际使用准确的工具和资料，不承诺排名、收录或AI引用。使用现有部署和免费能力，不购买关键词工具、排名服务、外链、素材、模型接口或新增云服务；既有服务器、OSS/CDN正常费用不因本计划变成免费。

## 本轮落实

- 首批5个城市缴费速查页及目录：北京、上海、南京、无锡、连云港。上下限、已接入比例、有效月份和来源从计算器引擎生成，说明采用Markdown维护。缺项不按零处理，页面整理日期与参数核查日期分开。
- 三个核心工具的折叠算例：五险一金、个税（工资及奖金）、离职补偿。所有输入明确为虚构，输出由计算引擎生成；点击可带入试算，不自动保存记录。
- 四个工作专题：社保公积金、工资奖金、合同劳动关系、表格清单，连接实际存在的政策、工具、模板与已发布文章。
- 首页HR工作资源加入上述入口，最新资讯继续6篇；详情保留正文、适用范围和页尾小字免责声明。
- 城市与专题说明可通过Pages CMS编辑Markdown，GitHub构建后发布。参数仍只在共用参数库维护，不通过CMS另抄一份数字。
- 工具使用WebApplication结构化数据，城市及专题详情补面包屑；只描述真实可见功能，不伪造评分、专家、组织背书。
- 日更从两篇调整为三篇，每篇约1500字。来源、正面脱敏实际案例、FAQ、内链、图片许可和移动排版标准不降低。无头图、正文只内链；原始URL留sources，政策页保留官方入口。

是否正式完成以Git提交、Actions、deployment-state与公网验收为准，不能把本地构建称上线。

## 每日行动

1. 按既有日更任务检索真实热点，优先从社保公积金、个税薪酬、劳动关系及HR表格的实际问题选题。当天只补足三篇，不倒填漏跑日期。
2. 对照近30日内容避免重复；一个主问题对应一篇，不用同义改写或换城市凑文章。新稿自然连接2—4个相关资源。
3. 内容审校与构建时检查来源、范围、图注、日期、内链、canonical和Sitemap。无实质变化不刷新lastmod。
4. 只维护Sitemap、robots与正常可抓取HTML；不恢复主动URL推送、IndexNow或Google逐页索引请求。

## 每周行动：合并到既有周一09:00任务

- 按《每周内容与政策更新》逐城逐字段复核，不抽样代替全量。执行 `python scripts/prepare_weekly_review.py` 先生成全部待核验清单，再逐项填写证据。该脚本不联网、不判断政策，不会自动把任何项标为核验通过。
- 检查城市页、专题、文章、工具算例之间的引用是否仍准确；政策变化后同步修改对应旧内容，历史事件保留原日期。
- 查404、断链、重复标题、canonical、Sitemap及关键页面360/390px布局，保证表格内部滚动、不导致整页横向溢出。
- 有已授权可读的免费站长统计时，记录实际查询词、曝光、点击和落地页；再核对文章进入工具、下载模板等已可观测动作。没有事件数据时写“未采集”，不靠访问量推算转化。
- 有必应AI Performance权限和数据时记录支持范围内的实际引用及被引用页面；其他AI检索仅作有限人工观察，不宣称覆盖全部平台或引用必然增加。
- 从有真实需求的页面继续加深内容；没有数据时优先核验准确性与可用性，不虚构搜索量、排名、引用和转化。
