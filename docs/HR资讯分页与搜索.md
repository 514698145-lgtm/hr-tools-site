# HR资讯列表

文章卡片不设01、02、03编号，以分类、发布日期、标题和摘要识别。首页展示最新3篇，资讯及分类列表按发布时间倒序，每页最多12篇。

- 电脑端：上一页、页码、下一页；文章过多时省略远端页码。
- 手机端：上一页、当前页/总页数、下一页；点击文章卡片进入全文。
- 不足一页不显示翻页按钮，空分类显示空态。
- 搜索覆盖当前栏目全部已发布文章，结果也按12篇分页；清空恢复进入页面时的列表。
- 正常列表的分页是静态HTML链接，例如 /insights/page/2/ 和 /insights/category/2/page/2/，有独立canonical与Sitemap；关闭JavaScript仍可翻页和读文章。
- Pages CMS继续编辑同一Markdown文章；新文章发布后GitHub构建自动重新排序、分组和生成分页，无需编辑页码。草稿和未来稿不进入公开搜索数据。

验证：25条虚构测试文章覆盖12/12/1分布、分类、空态、跨页搜索、边界翻页及安全转义。这些测试文章不发布到正式网站。当前正式HR资讯只有4篇，因此正常不出现分页条，不将测试页冒充已发布内容。
