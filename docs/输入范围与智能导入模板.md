# 输入范围与智能导入模板

更新：2026-10-01。当前实现说明，非历史版本手册。

| 模块 | 自动计算 | 仍需用户提供 |
| --- | --- | --- |
| 五险一金 | 按城市、月份和医保类型匹配已核验政策；工资按已核验上下限核定；个人与公司分列 | 真实缴费工资、单位公积金比例、核定工伤比例和缺依据参数 |
| 个税 | 工资累计预扣、奖金计税、全年对比 | 收入、扣除、已缴税和奖金使用情况；精确金额分配导入网站计算 |
| 离职补偿 | 根据日期算补偿月数、适用条件下封顶 | 已确定的计算类型、平均工资、当地有关工资标准 |
| 到手工资 | 应发减个人缴费、税额和其他扣款 | 实际金额，或从五险一金结果带入个人部分 |
| 用工成本 | 公司月成本、人数与期间总成本 | 工资及单位实际费用，可带入公司缴费结果 |
| 调薪预算 | 新工资、月增量、当年生效月数、年增量 | 旧工资、调整方式与金额/比例、生效月份 |
| HR数据速算 | 平均人数、比率、人数流转差异 | 统计期间、期初期末与入离职人数 |

网页和批量导入共用 input-rules.js。政策允许区间与技术数值边界分开说明；缺少可靠地方依据时不编造范围。普通公积金上海允许5/6/7档，其余结合已核验地方上限；全国5—12%外沿不等于所有地区可选任意比例。特殊降比不适用。真实工资不受基数上限限制。调薪可超过100%，人数必须整数，扣款不得超过工资。

七份 XLSX 含导入数据、自动测算、参数与依据、填写说明；预留2000条，上传上限10MB。输入表头标注必填、选填、条件必填。第一张表上传；公式输出不当作可信结果，网站重新计算。空输入行跳过，错误仍显示原始Excel行号。政策快照覆盖2026年月份，缺资料保留缺口，不跨期猜测。

## 维护步骤

1. 修改政策或计算规则后，运行 `node --max-old-space-size=8192 scripts/build_import_workbooks.mjs` 重新作者生成七份模板（依赖已配置的 artifact-tool）。
2. 运行 `python scripts/extend_import_rows.py` 扩展公式到2000条并生成内容哈希清单；输出同步到 outputs 和 public。
3. 在装有Excel的Windows上运行 `scripts/verify_import_excel.ps1`，再运行 `node scripts/check_import_workbooks.mjs reports/import-excel` 和 `node scripts/check_import_workbooks.mjs reports/import-excel-cases`。
4. 构建脚本校验政策、算法、模板内容哈希；过期模板会阻止构建。更新当前使用导览，不建立手册版本列表。

验证：49项JS、19项Python测试、93页静态检查、66项HR浏览器检查通过。真实Excel全量重算后20条常规示例及9条修改记录与网站一致；浏览器验证比例越界、移动/桌面布局、两条错误隔离与Excel第2001行导入通过。未部署。
