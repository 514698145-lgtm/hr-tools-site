# 网页字体与排版规范

全站网页正文使用真实 Regular（400），同级标题统一真实 Medium（500），按钮、表头及强调文本也使用500。不使用模拟粗体或临时混入其他字体。主标题、章节标题、卡片标题仍保留合理字号层级；同类组件的字重一致。

- 中文：HR Workspace Sans（由 Noto Sans CJK SC Regular/Medium 转换并改名的 WOFF2 子集）。许可证：SIL OFL 1.1；字库、授权、来源、哈希及覆盖清单位于 `public/fonts/hr-sans/`。
- 英文及数字：Inter 原始可变字体，SIL OFL 1.1；文件与许可位于 `public/fonts/inter/`。金额、数字输入和表格启用等高等宽数字。
- `public/assets/typography.css` 统一排版规则，所有生成页面共用，包含管理页、文章、政策、模板详情和动态计算结果。模块CSS只定义对应尺寸与布局；构建检查逐页确认已加载统一排版样式。
- 字体由本站提供，不使用外部字体CDN，不要求用户安装字体。常用字优先小包加载，其余原字库字符按Unicode范围加载；将来新增内容不必为了新汉字重新构建字库。
- 系统sans-serif仅作为字体尚未加载、网络加载失败或字库不支持的特殊符号回退；不打包或分发任何系统商业字体。品牌Logo是现有图片，不属于网页字体。
- 浏览器验收须检查实际字号、字重、行距、字体声明和横向溢出；不能只检查标题是否500就认为字号统一。通过可用的浏览器检查接口执行，核心页面保存截图。

## 手机端字号（2026-10-16）

760px及以下，共用卡片层级：工具、工作资源、资讯、政策列表、工作台工具标题16px/500，卡片描述13px/400，卡片入口12px，标签和资讯日期11px。标题行高1.6、描述1.8。首页资源卡片入口必须显式设字号，不能让strong继承15px页面正文；其他栏目也使用同一规则。章节标题18px，副标题另起一行11px，避免窄屏挤在同一行。

文章正文保留15px，长文标题、工具页标题、表单和结果金额分别保留自己的阅读层级，不把整页文字强制设成同一大小。移动表格仍在容器内横向滚动，不能为了字号统一造成整页横向滚动。

根元素设置`-webkit-text-size-adjust:100%`和`text-size-adjust:100%`，减少支持该属性的移动浏览器按文字块自动放大的差异；不设置`user-scalable=no`或`maximum-scale=1`，保留用户缩放。华为浏览器的系统字体设置、强制阅读模式等仍需真机核验，模拟窄屏不等于华为真机测试。属性依据：[MDN text-size-adjust](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-size-adjust)。
