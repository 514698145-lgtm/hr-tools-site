# 独立产品、匿名反馈与内容分类

日期：2026-09-27。仅本地实现，尚未部署。

## 独立产品

页面名称暂为 HR 工作站。去掉人力窝 Logo、英文品牌名及归属标语；保留暖白、暖金和少量深蓝的视觉。原品牌资产未删除，但不在页面引用。

## 每个工具的匿名吐槽

- 工具底部填写2—1000字反馈，无须注册，提交后公开显示。
- 工具各自独立留言，显示时间；管理员回复带明确身份标识。
- 管理入口 `/admin/feedback/`，密码登录后可回复、隐藏、恢复、退出。匿名用户没有管理权限。
- 本地 Node 服务把留言保存在 `.local/feedback.json`，写入排队并用临时文件替换；服务重启后保留。管理员会话重启失效。
- 本地随机管理密码仅生成在 `.local/admin-password.txt`；也可通过环境变量 HR_ADMIN_PASSWORD 设置。该目录不进入 Git 或 dist。
- 具有请求来源检查、长度限制、频率限制、纯文本输出和 HttpOnly 会话。本机所有请求来自同一地址，测试时也共享5分钟5条的提交限额。
- 当前读取每个工具最近100条，管理员查看全部；上限10000条。正式版应改数据库分页、备份、服务端限流及垃圾留言治理。
- 计算数据仍在浏览器本机；匿名留言是主动提交给评论服务的公开内容，两者不混用。

## 部署链路

公开页面仍采用 Pages CMS → Markdown → GitHub → 构建 → OSS → CDN。匿名留言不可只靠 OSS 保存，也不写回公开 GitHub Markdown。上线时应增加独立留言 API（可部署在阿里云计算服务）与数据库，使用 HTTPS、正式管理认证、备份和反滥用配置；不能把只监听127.0.0.1的本地预览服务器直接宣称生产服务。

页面确认前不部署，不开启定时任务。政策自动更新链路依然待实施；目前是带来源和有效月份的本地参数快照。

## 计算器进展与待补齐内容

五险一金结果分别汇总个人、公司，并显示各险种的基数、费率和金额。目录52个地区：内地50个（包含河北定州、辛集、雄安新区）和港澳2个；港澳仅说明不同制度，不计算。仅已核验且在有效月份内的字段自动应用，其他必填确认。全国/目标区域完整自动数据覆盖尚未完成。

个税分配明确发放前可调整薪酬构成与已发放整笔奖金两类；同年已使用一次单独计税时不再分配第二次。最低税额是输入条件及限制内的测算，不能当作修改税务申报的操作。

验证：20项Node计算/API测试、11项内容测试、40项基础浏览器检查、17项改版浏览器检查；18个HTML产物检查。浏览器覆盖PC与移动宽度，实际验证提交、管理员回复与隐藏，测试数据使用隔离临时目录，未写入用户的留言库。

## 后续功能修改的同步维护要求

用户明确要求使用导览是一份当前用户手册，不做版本列表或历史手册。每次修改用户操作、字段、输入限制、结果含义、批量导入、工作台或反馈流程时，同步更新 `content/guide.md`，直接替换当前内容。公开页面固定 `/guide/`；此要求不删除政策适用日期或保存结果的计算依据。

每个工具必须保留免责声明，具体文字集中在 `config/disclaimer.json`；新增工具时同时补充对应限制。模板的字段规则、虚构示例及留空影响在 `public/assets/import-template.js`；新增/删除/修改字段时也同步维护并验证下载后可重新导入。
