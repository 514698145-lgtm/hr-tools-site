# 放松一下：HR 待办消消乐

2026-10-04设计，用户已批准实施。2026-10-07完成本地实现与验证；暂不部署。

## 目标与入口

用户要求HR相关、热门玩法、耐玩、每日TOP20实时更新。建议网站侧栏与工具大厅增加「放松一下」，独立页面 /relax/；不是将游戏塞进管理员登录页。保留网站暖白暖金风格，游戏用低饱和辅助色。

## 核心玩法

参考成熟方块拼放消除机制，自制HR素材，不复制他人品牌、美术或代码。8×8棋盘代表桌面，每次发3个不同形状的待办块，拖入棋盘，填满行或列即可消除。待办图标用招聘、入职、考勤、薪资、培训、档案；仅作主题，不需识别颜色匹配，不涉及专业知识考试。

按用户最新要求改为每局随机的无尽模式，无固定关卡终点，取消60块上限及每日同题。每组3块全部放完再发下一组；剩余块均无法放置且无法使用暂存完成合法操作时结束，也允许主动结算。不设速度分，无倒计时压力，挂着不操作不得分。熟练玩家目标可持续15—30分钟或更久，仅为调参目标，需试玩验证。随时保存暂停。

每局使用独立随机种子；在统一形状池与难度规则下抽取方块，随机朝向在发出时确定，不能自行旋转。每10组提升一个难度阶段，大块、长条和不规则块的抽取权重逐步增加，达到上限后保持；具体权重经模拟和试玩定稿。设置一种非叠加的HR情境事件「招聘旺季」：每4—6组随机触发下一组较多大块，提前一组提示，不凭空占据棋盘，不按墙钟时间触发。开局不人为塞死局，后期不保证永远能放下，随机性会影响成绩，不宣称绝对同等局面。

增加一个「待办暂存位」：每组最多暂存或交换一次；暂存块保持形状和朝向，不重新抽取。可将难摆的块留到后面，但需腾出位置取回。暂存操作不加分。由暂存、连续消除、多线消除及随机形状构成策略深度，不堆叠复杂道具。不能撤销、复活，不加付费道具。鼠标/触摸拖拽，另支持点选块后点选位置及键盘操作。显示落点与可消除线预览。

暂定计分：落下每格1分；单步消除k条线得100×k²；连续有消除的落子，第c次额外20×min(c-1,5)，无消除则连击归零；清空棋盘另加300分。计分参数上线前试玩定稿，规则变化从下一个日榜生效。

耐玩点是每局随机组合、空间安排、多线消除与连续消除取舍、暂存时机及逐渐增加的难度。放置显示待办整理动画，消除提示「安排妥了」「这波很顺」，结束显示得分、今日最佳、排名及距第20名分差。音效默认关闭，支持减少动画。

## 温馨提示与快速返回（用户新增要求）

用户要求加入领导靠近时切屏等幽默摸鱼Tips。棋盘下方放一行「摸鱼小贴士」，可关闭，在开局/结算时换一条，不用弹窗打断游戏。按设备展示，经用户切换可查看其他平台。

- Windows：「脚步声靠近？Alt + Tab，切回已经打开的工作窗口。」；「Win + D 显示桌面，再按一次恢复窗口。」
- Mac：「工作来消息了？⌘ + Tab 切换应用。」；「⌘ + H 隐藏当前应用窗口，稍后再回来。」
- 通用：「声音默认关闭，快乐自己知道就好。」；「先把工作页面打开，切换时才有目的地。」；「歇一会儿，也记得让眼睛看看远处。」
- 手机：「右上角『回到工具大厅』，这一局先替你留着。」

页面提供常驻「回到工具大厅」按钮；点击先保存棋盘、发块位置、分数及完整操作序列再站内跳转。当前游戏页面获得焦点时，Esc作为同一动作快捷键（弹层优先关闭，输入框内不抢键；不全屏以免与退出全屏冲突）。页面失去焦点或进入后台时暂停输入/动画/音效，返回后用户点继续。不承诺网页能控制系统窗口或自动检测领导，不能描述为隐身/清除记录。保存与恢复不重抽方块，不加分，不改变跨日结算规则。

快捷键依据：Microsoft https://support.microsoft.com/en-us/windows/hardware/input-devices/windows-keyboard-tips-and-tricks 、Apple https://support.apple.com/en-ie/102650 。已实现设备适配提示、快速返回与暂停保存。

## 每日榜单规则

- 北京时间00:00开新榜，每局独立随机；所有玩家使用同一套形状池、难度曲线、事件分布与计分规则，排名仅按得分，不按用时。随机局面有运气因素。
- 可无限重试，每个匿名身份只取当天最高的已验证成绩。同分者同名次；TOP20最多20条，同分按首次取得该分的服务器时间先后展示，说明边界规则。
- 归属日由服务器开局时间确定；跨日旧局可继续练习但不补入昨日已封榜榜单，开局前说明。
- 延用现有匿名身份方案，昵称+短ID展示；清Cookie或换设备会产生新身份，不宣称一人一号。无虚拟玩家凑榜，少于20人按实际人数显示。
- PC左棋盘右榜单，手机棋盘后折叠榜单；我的最佳和排名始终单独可见。
- 每局结算经服务器验证后推送排行榜更新（SSE）；断线降级轮询并标注更新时间，不能把轮询称为瞬时实时。未连通服务时可以练习但不得显示虚构全站榜。

## 服务端与运营

静态页面仍沿用Pages CMS/Markdown/GitHub/OSS/CDN计划。对局、榜单和匿名身份必须走独立API与数据库，不写进Markdown、Git或OSS构建输出。复用身份凭据，不公开秘密令牌。服务器签发局ID、日期、每局独立随机种子和规则版本，提交操作序列后重放验证、重算分数、幂等结算；不信任客户端总分。刷新/恢复沿用原局随机状态，不能重新抽取；新局从0分开始。加入开局/提交频率限制，管理员可查看异常并撤销异常成绩。重放能防伪造分数，但不能彻底防自动解题和多匿名身份，首版不做有价值奖品。

验收需覆盖PC/手机控制、独立局随机发块、同局服务器重放一致、暂存合法操作与终局判定、阶段难度与事件分布、暂停恢复不重抽、消除计分、重复提交、跨日、身份隔离、同分边界、SSE断线恢复和伪造成绩拒绝。试玩后才能判断实际耐玩程度与一局长度。

## 本地实现与上线边界（2026-10-07）

- 页面 /relax/；侧栏及首页资源卡入口，底部接入匿名吐槽。/admin/game/ 共用反馈后台管理员登录，能撤销/恢复成绩，更新自动推送给游戏页面。
- 随机规则在 public/assets/relax-engine.js，客户端与服务器共用；服务端 scripts/game-api.mjs，经既有反馈API的匿名身份、来源校验及节流保护。每个动作核验并原子保存，客户端保存待重试操作；请求幂等，恢复不重抽。进度冲突可以恢复服务器进度。
- 分数仅按服务器规则计算。每日TOP20通过SSE通知更新，断线15秒轮询。北京时间换榜由服务器计算，无虚构玩家。暂停或挂后台不加分，跨日旧局不上新日榜。
- 当前数据 .local/game.json，单进程文件存储；保留近7天（开新局时清理），最多10000局。不能直接用于多实例生产。公开部署仍需独立API、数据库、备份、共享限流和SSE代理配置；OSS只放静态页面。身份秘密凭据不暴露到榜单、Markdown或Git。
- 实装形状池13种，每10组升一级、最高7级；招聘旺季间隔4—6组。无固定结束关，实际单局长度与耐玩程度仍需用户试玩；未声称已经验证所有玩家能玩15—30分钟。
- 自动验证：tests/relax.test.mjs 覆盖随机/重放、计分、暂存、难度、非法提交、匿名隔离、请求幂等、SSE、管理员、重启、午夜和TOP20同分边界；tests/relax-browser.mjs 使用隔离临时数据，覆盖拖拽/触摸、暂停刷新、响应丢失重试、Esc返回、跨浏览器实时榜、后台撤销恢复。reports/relax-review.json 与390/1440截图为验收记录。
