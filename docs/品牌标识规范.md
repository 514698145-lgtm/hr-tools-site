# HR工作站品牌标识

本网站独立使用的品牌名称为「HR工作站」，域名为 www.hrtoolkit.cn。2026-10-20 按用户要求设计并应用网站图标。

## 图形与颜色

原创几何 H 表示 HR / Human，右上角暖金方块表示可组合的工作工具。深蓝圆角方形底保证小尺寸识别；图形由纯矢量构成，不依赖字体或第三方图标。

| 用途 | 色值 |
| --- | --- |
| 深蓝底 / 品牌主色 | #263341 |
| 暖白 H | #FFFCF4 |
| 暖金工具方块 | #D8B66A |

## 母版与应用

- 唯一矢量母版：`public/brand/hrtoolkit-mark.svg`（64 × 64 viewBox）。保持比例、颜色及图形间距，不拉伸，不附加阴影或细小文字。
- 浏览器图标：`public/favicon.ico`，包含 16、32、48、256 像素；支持 SVG 的浏览器使用母版。
- 移动端主屏图标：`public/brand/apple-touch-icon.png`（180 × 180）。
- 通用高清图标：`public/brand/hrtoolkit-mark-512.png`（512 × 512）。
- 全站共享页面 head 引用图标；侧栏 / 移动端网站名称旁使用同一母版，桌面 32px、移动端 28px。网站字标继续使用已有免费商用字体。
- 图标是本站独立标识，不使用人力窝 Logo，不表示人力窝官方身份。服务合作及网站责任说明沿用当前页面声明。

## 更新方法

修改 SVG 母版后，用安装有 sharp 的 Node.js 执行 `node scripts/build_brand_icons.cjs` 重建 PNG / ICO。衍生文件提交仓库，日常静态构建不需要安装 sharp。导出后在 16 / 32px、明暗背景及桌面 / 手机布局检查识别度，重建 watch-manifest，经过现有发布门禁部署。不要仅替换一个尺寸而造成网站图标不一致。
