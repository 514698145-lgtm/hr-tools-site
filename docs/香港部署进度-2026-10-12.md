# 香港部署进度

截至2026-10-12，服务器已购买并运行：香港、2核2GB、40GB系统盘、Alibaba Cloud Linux 4。Node.js 22.23.0、Nginx 1.30.4、Git已从系统官方仓库安装。

## 后端准备

- scripts/runtime-server.mjs 为生产API入口，只监听127.0.0.1，不提供项目文件下载。需要配置正式HTTPS站点来源和绝对数据目录。
- deploy/hr-tools-api.service 为单实例systemd服务，异常退出重启；非登录服务账号hr-tools，持久数据置于/var/lib/hr-tools，程序置于/opt/hr-tools/current。
- deploy/runtime.env.example为公开配置示例；实际环境文件放在/etc/hr-tools/runtime.env，不进Git。
- 后端文件及systemd服务文件已复制到服务器，未启用服务。正式域名尚未确认，不能使用占位域名开启对外访问。
- 本机及服务器各通过6项API/游戏检查，覆盖HTTPS来源校验、管理员隔离、匿名身份Cookie、讨论持久化及日榜核验；这不是公网部署验收。
- 目前保持单进程文件存储，不扩多实例。正式开放前需配置备份、验证备份恢复，并结合实际规模评估数据库迁移。
