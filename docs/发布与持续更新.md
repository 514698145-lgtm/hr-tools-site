# 发布与持续更新实施规格

状态（2026-10-14）：正式部署已获用户授权，域名及云资源已购买，生产公网验收尚未完成。现有 GitHub 工作流覆盖内容、计算、来源清单、静态构建及产物检查，不含OSS上传。每周内容和政策维护已获授权，当前执行与验收要求见[每周内容与政策更新](每周内容与政策更新.md)。

## 内容链路

Pages CMS 修改 `content/articles/*.md` 和 `public/media/` → GitHub 提交 → 内容与计算测试 → 静态构建 → HTML/路由/SEO/响应式检查 → OSS/CDN 发布 → 线上核验 → 搜索通知。

文章地址：`/insights/{slug}/`。固定地址发布后不要随标题变化。路径变更必须单独维护重定向映射。
`status: draft` 不可生成公开 HTML、列表、Feed、Sitemap 或公开构建产物。`publishedAt` 晚于当前时刻亦排除。时间必须带时区。
仅填未来发布时间不会自动触发静态站重建。启用定时发布时必须同时部署云端调度与构建任务；当前未启用。
Markdown 渲染阶段禁用原始 HTML或做严格清洗，内容检查不能代替输出清洗。标题只在页面模板输出一次 H1。

## 五层质量检查

| 层级 | 必须验证 | 当前状态 |
| --- | --- | --- |
| 源内容 | 必填、日期、slug、重复字段、草稿过滤、媒体和关联工具 | 校验脚本已实现 |
| 计算 | 金额边界、政策版本、取整、累计个税、单条与批量一致 | 当前 6 工具、9 项测试；地方规则待接入 |
| 静态产物 | HTML、链接资源、唯一 Canonical、JSON-LD、真实 lastmod、Sitemap、草稿不泄露 | 构建器与基础检查已实现；正式域名/完整 Schema 验收待上线阶段 |
| 浏览器 | 手机/平板/PC、上传与下载、表格、键盘、无横向溢出 | 40 项浏览器断言通过；真机和全面无障碍检查待扩充 |
| 线上 | HTTPS、200/301/404、缓存后版本、页面正文与元信息 | 页面确认后实施 |

前四层关键错误应阻止生产发布。线上核验失败触发恢复。搜索通知失败不撤销正确的网站发布，独立保留失败清单再重试。

## OSS/CDN 发布要求（待实施，不是假定已具备）

- 仅上传构建输出目录，绝不上传项目根目录、文档、草稿、密钥或私人文件。
- 正式发布前启用 OSS 版本管理或独立 release 目录，保留上一产物与发布清单。
- 若使用根目录逐文件覆盖，应记录其不是原子切换。需处理旧文件清理、删除文章和发布中间状态；不可盲目递归删除 Bucket。
- 带内容哈希的资源长缓存；HTML、政策索引和 Sitemap 短缓存，发布时按变更刷新 CDN。
- CDN 请求目录路由须命中对应 `index.html`；不存在地址应是真 404，而非统一回首页 200。
- 恢复文件与数据版本后再处理 CDN 缓存，验证正式地址。
- 凭据只存 GitHub Environment/Secrets 或云端身份配置；不进入 `.pages.yml`、仓库或日志。
- 页面确认后才设置生产部署环境、默认分支与触发条件；不由定时任务自行取消发布限制。

## 政策更新

频率已确定为每周：周一北京时间08:17云端来源巡检，09:00智能复核。来源按城市和规则建立名单。每次保存采集时间、状态、内容指纹、来源 URL，区分初始基线、无变化、变化和采集失败。旧网页无变化不能代替官方新通知检索。
来源变化先生成候选记录。校验适用对象、生效期、基数/比例、区间冲突及回溯差额后生成新版本。用户已授权无歧义、有官方证据的例行内容与数值更新，仍须通过发布门禁；新公式或有歧义的规则不直接生效。
政策记录至少包含 `regionCode, ruleType, effectiveFrom, effectiveTo, publishedAt, verifiedAt, sourceUrl, parameters, version, status`。
一个批量任务绑定版本；历史结果不重写。政策导致既有文章过期时生成待复核清单，不直接重写作者全文。

## 搜索通知

- 构建保留内容路由清单及内容指纹，与上一次成功发布比较，计算新增、修改、删除和受影响列表页。
- CSS 改动不伪造文章更新时间；按 URL 去重并排除草稿、预览、工作台和私有结果。
- Google：Sitemap + Search Console 的适用接口/操作，不使用普通文章无资格使用的 Indexing API。
- Bing：核验域名与密钥后接入 IndexNow；删除 URL 与更新分别记录。
- 百度：上线接入时从已验证站点获取当前接口权限、额度和文档，再实施推送；当前未核实账户权限。
- 通知日志记录发布版本、平台、地址、HTTP 结果、接受情况、额度、重试次数；请求令牌不输出。
- 搜索平台反馈失败可重试，通知成功不能写成已收录或必然被 AI 引用。
