# MBTI趣味测试实现说明

用户授权先上线一个MBTI趣味模块，操作简单，内容与趣味环节更丰富。入口在日常工具，独立路由为/tools/mbti/，不进入计算器或批量模板生成逻辑。

## 题目与结果

- 32道本站原创生活/职场情境题，每组4题，4章各8题，各章混排四维；每维8题，两方向各4题。五级回答对应2、1、0、-1、-2，再按题目方向加总。百分比仅线性映射为本次倾向值，不是心理测量准确率、人群百分位或能力分数。
- 每维得分范围-16至16，左侧百分比round(50+sum/16*50)，右侧为其补数。原始和为0则显示X，绝对和与满分之比不超过1/6标“两边接近”。不随机决定类型，不用彩蛋修改类型。
- 四章为周一开机、灵感营业、协作现场、周末出逃；章节间3个小剧场可跳过。16个原创趣味名称与四项偏好文案，另展示主动选择的小彩蛋。
- 题目、计分、类型及趣味解读属于本站自编内容，没有心理测量学验证；清晰标注非官方MBTI测评，不用于招聘、绩效或心理诊断。不复制官方问卷、商业报告或16Personalities形象。

## 本机数据与集成

- 草稿仅保存在浏览器hr-personality-draft，读取时核对内部问卷标识、题号、数值范围与进度；从原48题进度保留仍在使用的题目答案，续答定位首个未答组，不要求全部重来。不兼容或损坏时回到开始页。存储失败时仍可完成本页测试，但提示无法保留。
- 手动保存到既有工作台hr-workspace-v1，以单条记录形式保存得分和小彩蛋，不保存逐题答案；收藏、最近使用、查看、表格导出与删除沿用工作台。
- 原48题保存结果按原先每维24分读取，新32题结果按每维16分读取，不能用新题量重新解释旧结果的百分比。
- 保存趣味卡生成1080×1440 PNG，采用本站自托管可商用字体，只包含结果和用户选择的小彩蛋；分享文案只带通用工具URL，不把个人答案编码进网址。
- 新工具有独立匿名反馈分类mbti；仅扩展既有API允许模块，不改变鉴权、权限、数据库或游戏逻辑。正式后端需同步runtime-server.mjs并重启单实例服务；部署前核对旧文件哈希，留原文件备份。
- 全站底部小字声明与当前使用导览已更新；SEO在既有Pages CMS页面SEO集合中维护。没有新增账号、付费API或云资源。

## 验收

计分专项覆盖16种方向组合、反向题、全中立/一律同意平衡、缺题及异常值、草稿恢复、旧进度迁移、旧结果数值兼容和彩蛋不计分。原48题端到端记录在reports/mbti-20261018/；32题本轮验证另见reports/mbti-nickname-20261022/。测试数据不是实际用户人格结论。
