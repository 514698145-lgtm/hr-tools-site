## 架构边界

公开文章、政策与工具前端可以静态构建。会员登录、跨设备私人记录和服务器批量任务需要独立鉴权 API、数据库及私有存储；OSS/CDN 不代替这些能力。浏览器本地保存不等于跨设备工作台。

Markdown 只保存公开文章。政策参数使用版本化结构数据；工资、员工记录、上传表格、访问令牌均不进入文章仓库、公开媒体或构建产物。

## 四篇文章在本项目的应用

1. 运营手册 → 固定产品边界、内容模型、发布链路与恢复要求。保留工具站的信息密度，不照搬展示站。
2. 设计规则 → 先确定布局、字号、断点、输入和结果状态；用同一套组件覆盖各工具。
3. 发布检查 → 源内容、计算、生成 HTML、响应式、线上 HTTP 五层分开验证。
4. 搜索通知 → 发布成功后才通知；失败可追踪；不把提交视为收录。
