# 设计规则草案（待页面确认）

参考只用于方法。未将事橙的配色、字体、图片或品牌内容视为本项目要求。

| 维度 | 设计基线 | 避免 | 验收 |
| --- | --- | --- | --- |
| 信息层级 | 工具名、输入、结果依次清晰；核心操作优先 | 首页大幅宣传占满首屏 | 手机首屏可看到工具入口 |
| 布局 | PC 输入与结果并排；手机顺序排列 | 只缩小桌面页面 | 360/390/768/1280/1440 像素检查 |
| 间距 | 共用 4/8/12/16/24/32 间距变量 | 每页另设一套间距 | 同类输入、标题、按钮一致 |
| 字体 | 表单至少 16px；数字等宽数字样式；正文舒适行距 | 为挤表格缩小到不可读 | 放大 200% 后内容可操作 |
| 色彩 | 正文、辅助文字、交互、成功与错误各有职责 | 仅靠颜色表达错误 | 错误同时有文字，文字对比度检查 |
| 图片 | 资讯有需要才使用图片；设置 alt 和尺寸 | 无关装饰影响计算 | 手机裁切不丢主体，无布局跳动 |
| 组件 | 输入、下拉、按钮、状态、结果卡和表格复用 | 每个工具重新设计 | 所有模块状态一致 |
| 交互 | 控件目标建议至少 44px；键盘可达；结果可定位 | 悬浮操作在手机不可用 | Tab、触屏、输入键盘、减少动画验证 |
| 表格 | 外层容器局部横向滚动；手机优先汇总 | 整页横向溢出、隐藏关键列 | 能查看全部数据并导出 |

工具状态：未填写、无效输入、计算中、成功、无适用政策、请求失败。
批量状态：未上传、解析中、映射字段、预览、待修正、计算中、部分成功、完成、失败。
工作台状态：未登录、空记录、加载中、正常、权限过期。

## 用户追加的 VI 要求与本轮落实

用户明确要求符合人力窝 VI，整体大气、高端。读取正式品牌档案并查看公司介绍封面与正式 Logo 后，采用：暖白 `#FBFAF7`、品牌暖金 `#D9AA3F`、浅金分区、深灰文字 `#363B43`；深蓝 `#123AA6` 仅作少量结构标识。

正式 Logo 来自品牌资产库，完整等比例展示，文件为 `public/brand/renliwo-logo.png`。没有重绘或变色。桌面统一侧边导航、内容左边界、留白和细边框；手机统一顶部导航与双列工具卡。首屏不过度拉高，仍可进入工具。

字体先尝试阿里妈妈普惠体/Alibaba PuHuiTi，继而思源黑体/Noto Sans SC，再使用系统中文字体。未从不明来源下载字体，也未假定用户设备已经安装品牌字体。

设计变量在 `public/assets/tokens.css`，品牌样式在 `brand.css`。这是已实现的第一版，仍等待用户对实际页面的确认。
